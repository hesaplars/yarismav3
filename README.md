# YiyosaGel v3

Flutter tabanli Android ve web uygulamasi icin temiz baslangic deposu.

## Hedef

- Native Flutter arayuz: Android ve web.
- Firebase Auth: misafir ve Google girisi.
- Firebase Cloud Functions: skor, altin, odul, magazalar, limitler ve raporlar gibi kritik islemler.
- Realtime Database: canli oda, sohbet, presence ve anlik oyun akisi.
- Firestore: profil, envanter, magazalar, raporlar, admin kayitlari ve ekonomi verileri.
- Firebase Cloud Messaging: Android bildirimleri.
- Guvenli odeme altyapisi: Google Play Billing ve web odeme saglayicisi.

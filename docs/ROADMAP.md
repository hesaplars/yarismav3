# Roadmap

## Phase 1 - Foundation

- Flutter app shell.
- Firebase initialization.
- Terms and access gate.
- Guest and Google auth flow.
- Profile, store and game mode shells.
- Secure Cloud Functions skeleton.

## Phase 2 - Core Game Ports

- Daily competitive session.
- Tour live room.
- Private room create/join.
- Word guessing daily and custom modes.
- Custom quiz create/play/comment/like/report.

## Phase 3 - Social

- User search.
- Friend requests.
- Direct messages.
- Blocking.
- Report center.
- Admin moderation queue.

## Phase 4 - Economy

- Daily login reward.
- Daily missions.
- Progress badges.
- Cosmetic inventory.
- YG limit unlocks.
- Store campaigns.

## Phase 5 - Production

- Android platform setup.
- Firebase App Check.
- FCM notifications.
- Google Play Billing.
- Web payment integration.
- Load testing and security rules tests.
- CI build pipeline.
